# chert labs

An experimental product lab from [Chert](https://www.trychert.com). We build games and apps that live inside FaceTime and iMessage: no app to install, you text a number or you call it. Everything is sold direct to the people who use it.

| | |
|---|---|
| **autophobia** | A week-long horror story told over text. Six new friends. [autophobia.tsc.hk](https://autophobia.tsc.hk) |
| **kyu** | Someone to text, honestly. A companion that lives in your messages. [kyu.tsc.hk](https://kyu.tsc.hk) |
| **strangers** | Call a number on FaceTime and talk to a stranger. [strangers.tsc.hk](https://strangers.tsc.hk) |
| **together** | Group FaceTime, streamed and in sync: camera grid, broadcast, watch party. Soon. |

How we build:

- **You text first.** We never message a number that hasn't messaged us.
- **Consent is per thing.** Recording, calls and training are separate opt-ins, and STOP always works.
- **No ads, no trackers.** You pay us, so you are the customer.

Built on the [Chert SDK](https://github.com/cherthq/sdk). Front page: [chertlabs/site](https://github.com/chertlabs/site).
